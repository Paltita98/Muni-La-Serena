Proyecto SGR - Sistema de Gestión de Resultados
Este es mi proyecto para la evaluación de la universidad (INACAP). Es el diseño de un sistema web para ayudar a las delegaciones municipales a organizar las actividades de los funcionarios y los compromisos con los vecinos.

¿Qué tiene este repositorio?
Diseño web (HTML): Son las pantallas del sistema (mockups). Tienen el diseño visual de cómo se vería la página para el perfil del Funcionario y del Administrador.

¿Cómo ver las pantallas?
No necesitas instalar ningún programa especial ni levantar servidores. Solo haz lo siguiente:

Descarga los archivos a tu computador.

Abre la carpeta donde se guardaron, un ejemplo es funcionario_demo, 
entramos y abrimos el templates, ahi encontraremos los archivos HTML. 

Haz doble clic en el archivo funcionario_demo.html o en admin_demo.html.

Se abrirá automáticamente en tu navegador de internet para poder ver el diseño.
